### 1. Fashion-MNIST 是什么

- 28×28 的灰度图，10 个类别（T 恤、裤子、套头衫、连衣裙、外套、凉鞋、衬衫、运动鞋、包、短靴）
- 训练集 60000 张，测试集 10000 张
- 每张图 = 28×28 = 784 个像素

### 2. root：数据存在哪

```python
mnist_train = torchvision.datasets.FashionMNIST(
    root="../data", train=True, transform=trans, download=True)
```

`root="../data"` 是**文件夹路径**，相对当前工作目录。下载下来的文件会放在那里：

```
data/FashionMNIST/raw/
    train-images-idx3-ubyte
    train-labels-idx1-ubyte
    t10k-images-idx3-ubyte
    t10k-labels-idx1-ubyte
```

换成绝对路径也行，比如 `/home/tintinzhang/data`。

### 3. download=True：没有就下

逻辑是“先看再下”：

1. 检查 `root` 下有没有那四个文件
2. 有 → 直接用，不联网
3. 没有 → 下载（大约 30 MB）

所以写 `download=True` 不会每次都重下。

如果写 `download=False` 而本地又没有，直接报错。

### 4. train=True / False

同一个类，两个实例：

- `train=True` → 60000 张训练图
- `train=False` → 10000 张测试图

数据一样，只是索引不同。

### 5. transform=trans：读进来就转格式

```python
trans = transforms.ToTensor()
```

原始数据是 PIL 图片：形状 (H, W)，取值 0–255 的整数。

`ToTensor()` 做两件事：

1. 转成 float32，除以 255 → 范围变成 0–1
2. 形状从 (H, W) 变成 (C, H, W)，即 (1, 28, 28)

为什么要除以 255：梯度下降对输入尺度敏感。0–255 的输入会让梯度爆炸。

### 6. show_images 逐行拆

```python
figsize = (num_cols * scale, num_rows * scale)
_, axes = d2l.plt.subplots(num_rows, num_cols, figsize=figsize)
axes = axes.flatten()
```

- `subplots(2, 3)` 造一张画布，上面 2 行 3 列共 6 个小格子
- 返回两个东西：整张画布 `fig`，以及格子数组 `axes`
- 第一个用不到，习惯写成 `_`
- `axes` 是二维的（2×3），`flatten()` 压成一维，方便一个循环走完

```python
for i, (ax, img) in enumerate(zip(axes, imgs)):
```

- `zip(axes, imgs)` 把“格子”和“图片”一对一配起来
- `enumerate` 顺便给个编号 `i`，用来取标题

#### ax 是什么

`ax` 是**一个子图**。`plt` 是“当前画布”，`ax` 是“指定的那一格”。

只有一个图时可以混用。多个子图时必须用 `ax`，否则所有图画在同一格里。

#### ax.imshow

```python
ax.imshow(img.numpy())
```

`imshow` 是“把二维/三维数组当成图片画出来”。不是画曲线（那是 `plot`）。

张量要先 `.numpy()`，因为 matplotlib 不认 torch 张量。

#### ax.set_title

```python
ax.set_title(titles[i])
```

给这一格加标题，显示在图片上方。没有标题就不画。

#### set_visible(False)

```python
ax.axes.get_xaxis().set_visible(False)
ax.axes.get_yaxis().set_visible(False)
```

关掉 x 轴和 y 轴的**刻度线和刻度值**。

不关的话，每张小图旁边会印 0、10、20 这些数字，六张图挤在一起非常乱。

它不改变图片本身，只是把坐标轴藏起来。

### 7. 一个最小例子

```python
import matplotlib.pyplot as plt
import numpy as np

fig, axes = plt.subplots(1, 2, figsize=(4, 2))
axes[0].imshow(np.random.rand(28, 28))
axes[0].set_title('左图')
axes[1].imshow(np.zeros((28, 28)))
axes[1].set_title('右图')
for ax in axes:
    ax.axes.get_xaxis().set_visible(False)
    ax.axes.get_yaxis().set_visible(False)
plt.show()
```
