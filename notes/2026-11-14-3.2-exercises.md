## 第 1 题：零初始化

### 结论

在 3.2 这个线性回归里，**算法仍然有效**。但它不是好习惯，换到多层网络就会出事。

### 为什么这里还能跑

零初始化时 `w = 0`、`b = 0`，预测全是 0。梯度：

```
∂L/∂w1 ∝ −Σ x1·y
∂L/∂w2 ∝ −Σ x2·y
```

两个梯度依赖不同的特征列，一般不相等。所以两个权重立刻分开走，不会卡死。

而且线性回归的损失是凸的，从哪出发都收敛到同一个最优点。零初始化只是起步慢一点。

### 为什么书里还要问

因为多层网络不一样。

如果隐藏层每个神经元的输入和参数都相同，零初始化后它们算出的梯度完全相同，更新后仍然相同。结果是：

- 一层里的 10 个神经元永远是同一个神经元
- 整个网络退化成“每层一个单元”
- 表达能力没了，怎么训练都上不去

这就是对称性问题。解决办法是随机初始化（甚至专门设计方差，比如 Xavier / He）。

### 一句话

零初始化在凸问题里死不了，在深层网络里活不成。

## 第 7 题：样本数不能整除批大小

### 结论

最后一批会变小，代码不会报错。

```python
batch_indices = torch.tensor(indices[i: min(i + batch_size, num_examples)])
```

切片 `indices[990:1000]` 如果只有 1000 条，最后一批是 10 条。如果只有 1003 条，最后一批是 3 条。

`min` 是防止“要 10 条但只剩 3 条”时切片写出界（其实 Python 切片本身会自己截断，写 min 只是更明确）。

### 会带来什么麻烦

1. **梯度尺度不一致**：3.2 的 `sgd` 里除了 `batch_size`（固定 10），而这一批只有 3 个样本。等效学习率被放大了 10/3 倍，最后一步可能过冲。
2. **形状变化**：如果下游代码假设 batch 形状固定，会出错。
3. **统计偏差**：最后一批的样本顺序有系统性（是剩下的那些），如果数据没打乱就更明显。

### 处理方式

- 丢掉最后一批：PyTorch 的 `drop_last=True`
- 或者按实际大小除以 `len(batch)` 而不是固定的 `batch_size`

## 第 2 题：电压和电流

### 结论

能。前提是模型形式由你指定，自动微分只负责调里面的参数。

### 模型

欧姆定律：

```
V = I · R
```

R 是要学的参数。这就是没有偏置的线性回归，一个特征、一个权重。

代码骨架跟 3.2 完全一样：

```python
R = torch.tensor(1.0, requires_grad=True)
for _ in range(1000):
    V_hat = I * R
    l = ((V_hat - V) ** 2).mean()
    l.backward()
    with torch.no_grad():
        R -= lr * R.grad
        R.grad.zero_()
```

只是把 `X @ w + b` 换成 `I * R`。

### 三个实际问题

1. **过原点。** 物理上 I = 0 时 V = 0，所以没有偏置项。如果电路有接触电势或零点漂移，就得把 b 加回来。
2. **量级。** 电压几百伏、电流几安，量级差大，不归一化收敛很慢。这正是 3.3 里归一化的动机。
3. **正数约束。** 电阻物理上大于 0，但无约束的梯度下降可能给出负数。常用 `R = exp(r)`，学 r，这样永远为正。

### 自动微分做不到的

它不能帮你发现模型形式。

白炽灯的 V-I 关系不是直线，因为灯丝电阻随温度变。用线性模型去拟合，只能得到某个工作点附近的局部斜率。

模型形式错，参数再准也没用。

## 第 3 题：普朗克定律反推温度

### 公式

```
B(λ, T) = (2hc² / λ⁵) / (exp(hc / (λkT)) − 1)
```

给定波长 λ 上测到的光谱能量密度 B，反推温度 T。

### 结论

能。这就是红外测温、色温测量、恒星温度估计的原理。

T 是唯一参数，把它设成可求导的张量，最小化光谱残差：

```python
T = torch.tensor(3000.0, requires_grad=True)   # 开尔文
for _ in range(2000):
    B_hat = planck(lam, T)
    l = ((torch.log(B_hat) - torch.log(B)) ** 2).mean()   # 对数域更稳
    l.backward()
    with torch.no_grad():
        T -= lr * T.grad
        T.grad.zero_()
```

用对数域是因为光谱能量跨好几个数量级，直接平方误差会被长波或短波端主导。

### 四个要点

1. **单参数，问题太好解。** 实际工程里更常用两个波长的**比值**（双色测温），因为比值可以把发射率约掉。
2. **真实物体不是黑体。** 观测是 `B_obs = ε(λ) · B(λ, T)`。发射率 ε 未知时，T 和 ε 会耦合，一组观测对应无穷多组解。这叫不可辨识。
3. **所以难点不在优化，在假设。** 要么假装 ε = 1（黑体近似），要么标定，要么用比值消掉它。
4. **传感器有带宽。** 测到的是一个波段积分，不是单波长点值，模型要跟着改。

### 一句话

自动微分能把 T 解出来，前提是模型形式（黑体 + 已知 ε）成立。假设错了，优化器只会认真地把错答案算到小数点后六位。
