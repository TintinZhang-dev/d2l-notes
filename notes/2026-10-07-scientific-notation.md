# exp(1.0) = 2.7183e+00,为什么?

> **In short:** `2.7183e+00` is scientific notation (2.7183 x 10^0). That `e` means *exponent*, not Euler's number.

- **日期:** 2026-10-07
- **章节:** 前置 / 数学基础
- **来源:** 看输出时的疑惑

## 我的问题

> 我看到 exp(1.0)=2.7183e+00 为什么?

## 卡在哪

这里有个**假朋友**:上一条刚学完 e ≈ 2.71828,输出里又冒出一个 `e`。两个 e 毫无关系。

## 想通了

**`2.7183e+00` 就是 2.7183。**

这是**科学计数法**。`e` 是 **exponent(指数)** 的缩写,意思是「× 10 的几次方」:

$$2.7183\text{e}+00 = 2.7183 \times 10^{0} = 2.7183$$

通用格式 `a e±bb` = a × 10^(±bb):

| 写法 | 等于 |
| --- | --- |
| `1e3` | 1000 |
| `1.5e-4` | 0.00015 |
| `2.7183e+00` | 2.7183 |
| `1.0e+10` | 10,000,000,000 |

### 两个 e,别混

| 写法 | 是什么 |
| --- | --- |
| 单独一个 `e` | 欧拉数,e ≈ 2.71828(**一个数**) |
| `2.7183e+00` 里的 `e` | exponent,「×10 的几次方」(**格式标记**) |

### 为什么会自动变成这样

数字太大或太小时,程序自动切科学计数法。但 2.7183 不大啊?常见两个原因:

1. **环境设成了固定科学计数法**(MATLAB 的 `format short e` 打印出来就是 `2.7183e+00`)
2. **同一个数组/张量里有大数** → 整行统一用科学计数法打印

Python 原生的 `math.exp(1.0)` 输出普通小数:

```python
>>> import math
>>> math.exp(1.0)
2.718281828459045
```

所以看到 `2.7183e+00`,基本是**数组打印**或**别的环境**。

## 怎么让它显示普通小数

```python
# PyTorch
torch.set_printoptions(sci_mode=False)

# NumPy
np.set_printoptions(suppress=True)
```

## 代码验证

```python
import torch, math

print(math.exp(1.0))                  # 2.718281828459045 ← 普通小数
print(torch.exp(torch.tensor(1.0)))   # tensor(2.7183)

# 张量里一旦有大数,整行都变科学计数法
print(torch.exp(torch.tensor([1.0, 50.0])))
# tensor([2.7183e+00, 5.1847e+21])
```
