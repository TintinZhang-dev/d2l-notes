> **In short:** Three questions. Q1: switching from summed loss to averaged loss divides the gradient by batch size, so the learning rate must be multiplied by batch size to keep the same step — smaller is wrong. Q3: the gradient lives in `.grad`; `.data` is the raw values and is used for in-place initialization.

## 题目原文

1. 如果将小批量的总损失替换为小批量损失的平均值，需要如何更改学习率？
2. 查看深度学习框架文档，它们提供了哪些损失函数和初始化方法？用 Huber 损失代替原损失。
3. 如何访问线性回归的梯度？

## 第 1 题：求和换平均，学习率怎么改

### 我的答案

学习率变小。

### 反了，要变大

推导：

```
L_sum  = Σ l_i
L_mean = (1/b) Σ l_i

∂L_mean = (1/b) · ∂L_sum
```

梯度小了 b 倍。

要保持每步的位移一样：

```
lr_mean · (1/b) · g = lr_sum · g
lr_mean = b · lr_sum
```

所以学习率要**乘 b**。b = 10 时，原来 0.03，现在要 0.3。

### 为什么 3.3 的代码看起来少了一步

3.2 手写版：

```python
def squared_loss(y_hat, y):
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2   # 返回向量

l = loss(net(X, w, b), y)
l.sum().backward()          # 求和
sgd(...)                    # 里面除了 batch_size
```

3.3 框架版：

```python
loss = nn.MSELoss()         # 默认 reduction='mean'，已经求平均
l = loss(net(X), y)
l.backward()
trainer.step()              # 不再除 batch_size
```

`MSELoss` 默认就是平均，所以 `SGD` 里不再除批量大小。这一步被藏进损失函数了。

两边配合着看才明白：**除 batch_size 这件事没有消失，只是换了地方。**

## 第 3 题：怎么访问梯度

### 梯度在 .grad，不在 .data

```python
l.backward()
print(net[0].weight.grad)   # 梯度，形状同 weight
print(net[0].bias.grad)     # 偏置的梯度
```

`.grad` 在第一次 `backward()` 之前是 `None`。

### .data 是什么

```python
print(net[0].weight.data)   # 数值本身，不带计算图
```

`.data` 拿到的是同一块内存里的数值，但绕过了 autograd 记录。

所以初始化时这么写：

```python
net[0].weight.data.normal_(0, 0.01)   # 原地改数值，不进计算图
net[0].bias.data.fill_(0)
```

如果用 `net[0].weight.normal_(0, 0.01)`，会因为“叶子张量原地操作”报错——跟 sgd 里必须套 no_grad 是同一个原因。

### 三个东西分清

| 写法 | 是什么 |
| --- | --- |
| `net[0].weight` | Parameter 对象本身 |
| `net[0].weight.data` | 数值，不带梯度记录 |
| `net[0].weight.grad` | 梯度 |

### 另一种访问方式

```python
g = torch.autograd.grad(l, net[0].weight)[0]
```

不依赖 `.grad` 缓存，也不受 `zero_grad()` 影响。
