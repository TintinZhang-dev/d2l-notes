# torch.mv 与矩阵乘法家族

> **In short:** `torch.mv` = matrix × vector (2D × 1D only); `mm` = 2D × 2D; `bmm` = batched 3D; `matmul` / `@` = general. More specific is faster, more general is safer.

- **日期:** 2026-10-17
- **章节:** 2.3.8 矩阵-向量积
- **来源:** 不认识 `torch.mv`

## 我的问题

`mv` 是什么？

## 想通了

`mv` = **m**atrix × **v**ector。

```python
torch.mv(A, x)          # 等价于下面两个
torch.matmul(A, x)
A @ x
```

### 两个限制

- 只吃 **2D 矩阵 × 1D 向量**；`x` 是 `(n,1)` 会报错
- 不支持批次

### 家族表

| API | 形状 | 说明 |
| --- | --- | --- |
| `torch.mv(A, x)` | (m,n) × (n,) → (m,) | 矩阵 × 向量 |
| `torch.mm(A, B)` | (m,n) × (n,p) → (m,p) | 矩阵 × 矩阵 |
| `torch.bmm(A, B)` | (b,m,n) × (b,n,p) | 批量 |
| `torch.matmul` / `@` | 通用，含广播 | 首选 |

**规律：越专用越快，越通用越安全。** 平时写 `@`，明确形状时再用 `mv` / `mm`。

## 代码验证

```python
import torch
A = torch.tensor([[1., 2., 3.], [4., 5., 6.]])
x = torch.tensor([1., 10., 100.])
torch.mv(A, x)          # tensor([321., 654.])
torch.mv(A, x).shape    # torch.Size([2])
```
