> **In short:** `lambda` is Python's anonymous function. `lambda X: d2l.linreg(X, w, b)` makes a one-argument function that closes over the current `w` and `b`, which is exactly what the training loop expects when it calls `net(X)`.

## 卡在哪

## 想通了

### 1. 两个 λ，先分清

| 写法 | 含义 |
| --- | --- |
| 数学里的 λ | 正则化强度，一个数 |
| Python 里的 lambda | 匿名函数 |

4.5 这节两个都会出现。看到 `lambda X:` 这种带冒号的，是函数。

### 2. 原文那行

```python
net, loss = lambda X: d2l.linreg(X, w, b), d2l.squared_loss
```

等于：

```python
def net(X):
    return d2l.linreg(X, w, b)

loss = d2l.squared_loss
```

`lambda 参数: 表达式` 直接返回表达式的值，不用写 `return`。

### 3. 为什么要包一层

训练循环是这样调的：

```python
l = loss(net(X), y)     # 只传 X
```

但 `d2l.linreg` 需要三个参数：`linreg(X, w, b)`。

lambda 把 `w`、`b` 提前绑进去，只留一个 `X` 当接口。这样训练循环不用改。

这叫**闭包**：lambda 记住定义时外面的 `w` 和 `b`。

### 4. 还有一个地方出现

4.2 和 4.6 里：

```python
trainer = d2l.Trainer(max_epochs=10, num_epochs=..., updater=
              lambda batch_size: d2l.sgd(params, lr, batch_size))
```

一个道理：框架要求 updater 只接收 `batch_size` 一个参数，所以把 `params`、`lr` 包进去。

### 5. 语法限制

lambda 里只能写**一个表达式**，不能有语句。

```python
lambda X: X * 2              # 可以
lambda X: print(X)           # 可以（print 返回 None）
lambda X: y = X + 1          # 不行，赋值是语句
```

复杂逻辑就用 `def`。

### 6. 什么时候该用，什么时候别用

该用：只在一处用到、逻辑一行、当参数传给别的函数。

别用：需要调试（报错只有 `<lambda>`，没有名字）、逻辑超过一行、要复用。

## 代码验证

```python
w, b = 2, 3
f = lambda x: w * x + b
g = lambda x: x * 2

print(f(5))        # 13
print(g(5))        # 10
print(type(f))     # <class 'function'>

# 等价写法
def h(x):
    return w * x + b
print(h(5))        # 13
```

## 一句话

lambda 就是"临时起个函数，不起名字"。它记住外面的变量，只留你指定的参数。
