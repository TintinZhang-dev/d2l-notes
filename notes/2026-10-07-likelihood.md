# 3.1.3 似然看不懂

> **In short:** Likelihood is probability read backwards. Under Gaussian noise, minimizing MSE *is* maximum likelihood estimation.

- **日期:** 2026-10-07
- **章节:** 3.1.3 正态分布与平方损失
- **来源:** 看书卡住

## 我的问题

> 3.1.3 似然我没太理解。

## 一句话

**似然 = 把「概率」反着读。** 同一个公式:

- 固定参数,问「这份数据有多可能出现」→ 叫**概率**
- 固定数据(已经看到了),问「哪组参数最能解释它」→ 叫**似然**

方向一翻,名字就换了。这就是全部困惑的来源。

## 一、先把「似然」翻译成人话

| | 固定的 | 要问的 | 名字 |
| --- | --- | --- | --- |
| 正着读 | 参数 w, b | 这组参数下,看到这份数据的可能性多大? | 概率 |
| 反着读 | 数据(已观测) | 哪组参数最可能生成这份数据? | **似然** |

写出来是**同一个式子** $P(y \mid \mathbf{x})$。区别只在于「你心里把谁当成已知」。

## 二、线性回归里怎么用上它

书里的假设:

$$y = \mathbf{w}^\top \mathbf{x} + b + \epsilon, \qquad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

**翻译:真实关系是线性的,但每次观测都掺了一撮高斯噪声。**

既然噪声是正态分布,那给定 x,观测到 y 的概率就是:

$$P(y \mid \mathbf{x}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y - \mathbf{w}^\top\mathbf{x} - b)^2}{2\sigma^2}\right)$$

**盯住指数里那一项**:$(y - \hat y)^2$,就是「预测误差的平方」。

> 误差越小 → 指数越大 → 概率越大

高斯分布中间高两边低,所以「误差小」天然对应「可能性大」。

## 三、整个数据集:概率要相乘

假设样本**独立同分布**。独立事件的联合概率 = 各自概率相乘:

$$P(\mathbf{y} \mid \mathbf{X}) = \prod_{i=1}^{n} P(y^{(i)} \mid \mathbf{x}^{(i)})$$

**极大似然估计 = 找一组 w, b,让这个乘积最大。**

## 四、为什么马上要取对数

| 问题 | 取 log 之后 |
| --- | --- |
| n 项连乘 → 数值下溢到 0 | 连乘变连加,数值稳 |
| 指数函数的乘积没法直接求导 | 指数被 log 消掉,变成多项式 |

而且 **log 单调递增** → 最大化 $\log P$ 和最大化 $P$ 完全等价,不改变答案。

## 五、展开算一遍(关键步骤)

$$\log P(y \mid \mathbf{x}) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y - \hat y)^2}{2\sigma^2}$$

对 n 个样本求和,再取负:

$$-\log P(\mathbf{y} \mid \mathbf{X}) = \sum_{i=1}^{n}\left[\frac{1}{2}\log(2\pi\sigma^2) + \frac{(y^{(i)} - \hat y^{(i)})^2}{2\sigma^2}\right]$$

拆成两块:

$$= \underbrace{\frac{n}{2}\log(2\pi\sigma^2)}_{\text{跟 } w, b \text{ 无关}} + \underbrace{\frac{1}{2\sigma^2}\sum_{i=1}^{n}(y^{(i)} - \hat y^{(i)})^2}_{\text{就是 MSE} \times \text{常数}}$$

**第一项不依赖 w, b,直接丢掉。第二项就是均方误差。**

## 六、结论

> 在高斯噪声假设下,**最小化均方误差 = 对线性模型做极大似然估计**。

这就是「为什么回归用平方损失」的理论依据,不是拍脑袋定的。

## 七、一个很值的延伸

**惩罚项的形状,取决于你假设什么噪声:**

| 噪声假设 | 取 log 后掉出来 | 损失函数 |
| --- | --- | --- |
| 高斯分布 | $(y - \hat y)^2$ | MSE(平方损失) |
| 拉普拉斯分布 | $\lvert y - \hat y \rvert$ | MAE(绝对值损失) |

所以「用 MSE 还是 MAE」本质上是在赌噪声的分布。
