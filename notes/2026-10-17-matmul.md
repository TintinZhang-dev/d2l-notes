# 矩阵-矩阵乘法：形状规则与三条性质

> **In short:** (m×n)(n×p) → (m×p); not commutative, associative, transpose reverses order. Cost is m·n·p multiplications — this is where most deep-learning compute goes.

- **日期:** 2026-10-17
- **章节:** 2.3.9 矩阵-矩阵乘法
- **来源:** 想知道这一节在讲什么

## 我的问题

2.3.9 是什么？

## 想通了

**定义**：`C[i,j] = A 的第 i 行 · B 的第 j 列`

口诀：**中间的 n 必须相同，两头的 m 和 p 留下来。**

```
A = [[1,2,3],        B = [[1,2],
     [4,5,6]]             [3,4],
                          [5,6]]
A: 2×3   B: 3×2   →   AB: 2×2

C[0,0] = 1*1 + 2*3 + 3*5 = 22
C[0,1] = 1*2 + 2*4 + 3*6 = 28
C[1,0] = 4*1 + 5*3 + 6*5 = 49
C[1,1] = 4*2 + 5*4 + 6*6 = 64
```

反过来 `BA` 是 3×3，完全不同。

### 三条性质

1. **不满足交换律**：`AB ≠ BA`，有时连形状都对不上
2. **满足结合律**：`(AB)C = A(BC)` ← 先乘哪两个结果一样，**但代价可以差很多**
3. **转置反序**：`(AB)ᵀ = BᵀAᵀ`

### 为什么重要

- 代价 = **m·n·p** 次乘法 → 深度学习 90% 的算力花在这上面
- GPU 的核心就是为 matmul 设计的
- 卷积在实现时会转成 matmul（**im2col**）→ 2.3.9 是 CNN 的性能地基

## 代码验证

```python
import torch
A = torch.tensor([[1., 2., 3.], [4., 5., 6.]])
B = torch.tensor([[1., 2.], [3., 4.], [5., 6.]])
A @ B    # tensor([[22., 28.], [49., 64.]])
B @ A    # shape: torch.Size([3, 3])
```
