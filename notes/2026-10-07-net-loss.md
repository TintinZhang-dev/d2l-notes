# net() 和 loss() 是什么?

> **In short:** `net` and `loss` are just variables holding a function or an object. The same names work for the from-scratch and framework versions.

- **日期:** 2026-10-07
- **章节:** 3.2 从零开始实现
- **来源:** 书里讲得太快

## 我的问题

> loss()、net() 书里讲得太快。

## 卡在哪

`net` 和 `loss` 是哪儿冒出来的?前面只定义了 `linreg` 和 `squared_loss`,没有 `net`、`loss`。

## 答案就两行

书里确实定义了,只是夹在一堆超参数中间,一笔带过:

```python
lr = 0.03
num_epochs = 3
net = linreg          # ← 就是这两行
loss = squared_loss
```

**`net` 和 `loss` 只是变量名,里面装的是函数。**

## 一、Python 里函数可以赋值给变量

```python
def linreg(X, w, b):
    return torch.matmul(X, w) + b

net = linreg            # 把函数本身赋给 net
```

所以 `net` 就是 `linreg`,完全等价:

```python
net(X, w, b)      # 等于
linreg(X, w, b)
```

### ⚠️ 经典坑:加不加括号

```python
net = linreg              # ✅ net 是函数本身
net = linreg(X, w, b)     # ❌ 这是调用结果(一个张量),不是函数
```

**没括号 = 函数本身;有括号 = 立刻调用。** 差一个括号,行为天差地别。

## 二、书为什么这么写?为了给 3.3 铺路

3.3 简洁实现里:

```python
net = nn.Sequential(nn.Linear(2, 1))   # 也叫 net
loss = nn.MSELoss()                     # 也叫 loss
```

**同样的名字,换成了框架对象。** 于是训练循环几乎不用改:

| | 3.2 从零 | 3.3 简洁 |
| --- | --- | --- |
| `net` 是什么 | 函数 `linreg` | 对象 `nn.Sequential(...)` |
| 参数在哪 | 外面 `w, b`,自己管 | 藏在 `net` 内部 |
| 怎么调 | `net(X, w, b)` | `net(X)` |
| `loss` 是什么 | 函数 `squared_loss` | 对象 `nn.MSELoss()` |
| 返回什么 | **向量** `(batch, 1)` | **标量**(已取平均) |
| 所以 | 要 `l.sum().backward()` | 直接 `l.backward()` |

**书里讲得快,是因为它在做「接口对齐」,不是教新语法。**

## 三、对象为什么也能写成 net(X)

`net(X)` 这种写法看着像函数调用。其实**任何定义了 `__call__` 的对象都能这么写**。

`nn.Sequential` 定义了,所以照样 `net(X)`。这就是两种东西能共用一个写法的原因。

## 四、嵌套那行拆开看

```python
l = loss(net(X, w, b), y)
```

从里往外读:

```python
y_hat = net(X, w, b)   # 1. 先算预测
l = loss(y_hat, y)     # 2. 再算损失
```

嵌套只是省了一行。

## 五、和前面 `l.sum()` 接上

- 3.2 的 `squared_loss` 返回**向量** → 所以要 `l.sum().backward()`
- 3.3 的 `nn.MSELoss()` 默认已经取平均 → 直接 `l.backward()`

**同一个 `.sum()` 的疑问,在这里闭环了。**

## 代码验证

```python
import torch

def linreg(X, w, b):
    return torch.matmul(X, w) + b

def squared_loss(y_hat, y):
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2

net = linreg
loss = squared_loss

X = torch.tensor([[1.0, 2.0]])
w = torch.tensor([[2.0], [-3.4]])
b = 4.2
y = torch.tensor([[0.0]])

print(net(X, w, b))            # tensor([[-0.6000]])
print(linreg(X, w, b))         # 一模一样
print(loss(net(X, w, b), y))   # tensor([[0.1800]]) ← 是 1×1 张量,不是标量
print(type(net))               # <class 'function'>
```

最后一行注意:损失出来是**张量**,不是数。这就是要 `.sum()` 的原因。
