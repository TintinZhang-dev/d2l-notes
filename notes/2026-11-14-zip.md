> **In short:** `zip` is a Python builtin that pairs up several iterables element by element, stopping at the shortest. In `corr2d_multi_in` it pairs each input channel with its matching kernel so the per-channel correlations can be summed.

## 我的问题

## 卡在哪

## 想通了

### 1. Python 内建函数

`zip` 不用导入，直接可用。

作用：把几个序列**按位置配对**，返回一个迭代器。

```python
a = [1, 2, 3]
b = ['a', 'b', 'c']

print(list(zip(a, b)))
# [(1, 'a'), (2, 'b'), (3, 'c')]
```

配对结果的长度由**最短的那个**决定：

```python
list(zip([1, 2, 3], ['a', 'b']))
# [(1, 'a'), (2, 'b')]   第三个丢了
```

Python 3.10 之后可以加 `strict=True`，长度不一致直接报错。

### 2. 在 corr2d_multi_in 里

```python
def corr2d_multi_in(X, K):
    return sum(d2l.corr2d(x, k) for x, k in zip(X, K))
```

X 形状 `(c_in, H, W)`，K 形状 `(c_in, h, w)`。

`zip(X, K)` 把第 0 维（通道）配对：

```
(X[0], K[0]), (X[1], K[1]), ..., (X[c-1], K[c-1])
```

然后对每一对做一次二维互相关，把所有通道的结果**加起来**。

这就是多输入通道卷积的定义：每个通道各算一遍，再求和。

### 3. 展开成不用 zip 的写法

```python
def corr2d_multi_in(X, K):
    out = d2l.corr2d(X[0], K[0])
    for i in range(1, len(X)):
        out += d2l.corr2d(X[i], K[i])
    return out
```

完全等价。zip 只是让写法短一点。

### 4. 和生成器表达式配合

```python
sum(d2l.corr2d(x, k) for x, k in zip(X, K))
```

拆开看：

1. `zip(X, K)` 逐个吐出配对
2. `for x, k in ...` 把每对拆成两个变量
3. `d2l.corr2d(x, k)` 算一个通道的结果
4. `sum(...)` 全部加起来

四步一行。

### 5. zip 的另一个常见用法：转置

```python
rows = [(1, 2, 3), (4, 5, 6)]
print(list(zip(*rows)))
# [(1, 4), (2, 5), (3, 6)]
```

`*` 把列表拆成多个参数，于是变成 `zip((1,2,3), (4,5,6))`。

这个技巧在数据预处理里常出现。

### 6. 前面的地方也用过

3.5 的 `show_images`：

```python
for i, (ax, img) in enumerate(zip(axes, imgs)):
```

把“格子”和“图片”一对一对起来，一次循环处理一张。

同一个函数，换了场景。

## 代码验证

```python
X = [[1, 1], [2, 2], [3, 3]]    # 3 个通道
K = [[0, 0], [0, 0], [0, 0]]

for x, k in zip(X, K):
    print(x, k)

print(list(zip('abc', [1, 2])))       # 长度 2

# Torch 张量也能 zip（按第 0 维）
import torch
Xt = torch.arange(6).reshape(2, 3)
Kt = torch.ones(2, 3)
print([(x.shape, k.shape) for x, k in zip(Xt, Kt)])
```

## 一句话

zip 就是拉链：两边同时往下走，一格一格对上。
