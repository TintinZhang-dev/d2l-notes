# backward() 到底是什么?

- **日期:** 2026-10-07
- **章节:** 2.5 自动微分
- **来源:** 顺着 `z.sum().backward()` 往下问

## 我的问题

> backward

## 一句话

**backward() 是自动微分的「触发键」。** 调它,梯度才开始算。

## 它做了三件事

1. **往回走** — 从你调用 backward 的那个张量出发,沿计算图反向走一遍
2. **用链式法则** — 每步把局部导数乘起来
3. **写进 `.grad`** — 写到**叶子张量**上,不是返回值

`backward()` 的返回值是 `None`。结果只能去 `x.grad` 里拿。

## 计算图是什么

你做运算的时候,PyTorch 在偷偷记账:

```python
x = torch.tensor(2.0, requires_grad=True)   # 叶子
a = x * 3      # 记一笔:a = x * 3
b = a ** 2     # 记一笔:b = a²
b.backward()   # 往回走:b → a → x
print(x.grad)  # tensor(36.)
```

验算:$b = (3x)^2 = 9x^2$,$\dfrac{db}{dx} = 18x = 36$ ✓

## 三个必须记住的点

### 1. 在「输出」上调,不在「输入」上调

```python
b.backward()   # ✅ 对输出 b
x.backward()   # ❌ x 是叶子,它不知道自己该对谁求导
```

### 2. 输出必须是标量

见 [z.sum().backward()](2026-10-07-sum-backward.md)。

### 3. `.grad` 是累加的

```python
x.grad.zero_()   # 训练循环里每轮都要清
```

## 另一个入口:torch.autograd.grad

`backward()` 是「副作用式」(写进 .grad),`autograd.grad` 是函数式(直接返回):

```python
g = torch.autograd.grad(b, x)   # (tensor(36.),)
```

想拿梯度又不想污染 `.grad`,用这个。

## 它在训练循环里的位置

```python
for X, y in data_iter:
    l = loss(net(X), y)   # 前向:顺便建图
    l.backward()          # 反向:算梯度
    trainer.step()        # 用梯度更新参数(内部会清零)
```

**前向建图 → backward 算梯度 → 优化器更新。** 这三步是所有深度学习的骨架。

## 代码验证

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
a = x * 3
b = a ** 2

print(b.backward())   # None ← 返回空
print(x.grad)         # tensor(36.)

# 非叶子张量(比如 a)默认不保留 .grad,拿到的是 None

# 函数式写法
print(torch.autograd.grad(b, x, retain_graph=True))   # (tensor(36.),)
```
